# Android application

See the [project README](../README.md) for installation and [build guide](../docs/BUILD.md) for local builds and GitHub releases.

## Controls

- Drag or pinch the globe; double-tap or use the target icon to recenter.
- Select a map marker or choose **Switch location**. The picker has separate selection and expand targets, with country/city/server search.
- Swipe the card or use **Location**, **DNS**, and **Tools**. Pages scroll vertically when needed. The unfolded card sits at the bottom right and fits its contents.
- **Content blocking** disables all DNS filters or restores the last nonzero selection. Ads, trackers and malware can also be selected individually.
- **Tools** has refresh, pairing, licenses, a Vanadium check shortcut and the location-notification switch.

## Pairing and privacy

Import the JSON generated by the gateway installer. The app accepts literal Tailscale IPv4 HTTPS endpoints, with the certificate and token supplied by the same file. TLS hostname verification remains enabled and HTTP redirects are rejected. A name is optional, so older pairing files still work.

Credentials are encrypted in app-private storage with Android Keystore; Android backups are disabled. No telemetry, map tiles or analytics are requested. Normal app requests go only to the paired gateway. The connection-check button explicitly opens Mullvad's website in Vanadium.

Pairing replacement resets location, DNS and notification caches. Requests from the previous gateway cannot overwrite the new pairing's state.

## Battery behavior

Status checks run every 15 seconds while the activity is visible, or briefly faster while a gateway change is running. They stop when the activity pauses. An in-flight request may finish, but it does not schedule another background poll.

The optional notification reuses these status results. There is no background service, boot receiver, scheduled worker, alarm or wake lock. Android may dismiss or expire the notification. The globe renders when its state changes and pauses with the activity.
